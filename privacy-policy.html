RefreshMate Privacy Policy

Short version: RefreshMate does not collect or transmit your browsing data. All settings stay in your browser. The only network request is premium license validation. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

01Data Collection

RefreshMate does not collect any personal data:

  • Browsing history or URLs visited
  • Page text, images, or content
  • Cookies or tracking identifiers
  • Usage analytics or telemetry

02Permissions

The extension requests only these permissions:

  • activeTab — Accesses the current tab only when you interact with the extension popup.
  • tabs — Finds and refreshes tabs matching the target domain.
  • storage — Saves your per-site refresh settings locally. No data is uploaded.
  • alarms — Schedules auto-refresh timers. Intervals from 5 seconds upward are supported; shorter ones run on in-background timers.
  • notifications — Shows browser notifications when monitored keywords appear or disappear.
  • offscreen — Creates a hidden document used only to play the alert sound — Chrome / Edge only; the Firefox build runs this in the extension background script and does not request this permission.
  • All sites (host permission) — A small content script draws the refresh overlay (countdown, pause button, status) on the pages you visit and asks the background for the remaining refresh time of the current site. It renders its own interface only: it never reads, stores, or transmits page content, and it stays inactive in the background while no page is open.

03Data Storage

All settings are stored locally in your browser using storage.local. Data is automatically deleted when you uninstall the extension.

04Third-Party Services

RefreshMate connects to one external service for premium license validation only:

  • License activation/verification — When you activate or validate a licence, a request is sent to api.annmax1983.com. It contains your licence key, a random install identifier, the plugin identifier and basic browser metadata (browser name and major version, interface language, time zone and user-agent string). No browsing data or page content is included.
  • Frequency — A licence check runs at most once every 2 hours. If the server cannot be reached, the cached licence keeps working until the next successful check.
  • What is NOT sent — URLs, page text, browsing history, cookies, or any personal information.

05Distribution & Code

RefreshMate is distributed exclusively through the Chrome Web Store, Microsoft Edge Add-ons and Firefox Add-ons (AMO). Source code is not distributed to end users. No ads, no tracking, no hidden data collection.

06Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them.

07Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.
