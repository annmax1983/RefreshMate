# RefreshMate
[English](../README.md) | 中文 | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

轻量级浏览器扩展，支持自定义间隔自动刷新页面，并在关键词变化时提醒你。

> 基于 Chromium · Manifest V3 · 最小权限 · 本地处理

---

## 为什么选择 RefreshMate？

需要监控页面变化？RefreshMate 按你的计划自动刷新页面，并在关键词出现或消失时提醒你——非常适合股票监控、抢票或任何对时间敏感的页面。

| 优势 | 说明 |
|------|------|
| ⏱️ **自定义间隔** | 快捷预设（5秒/30秒/1分钟/5分钟）+ 自定义输入 |
| 🎲 **随机间隔** | 防检测的随机范围，避免被网站拦截 |
| 🔔 **关键词提醒** | 关键词出现/消失时发送浏览器通知 |
| 🔒 **验证码检测** | 检测到验证码时自动停止刷新 |
| 💾 **站点独立设置** | 每个域名独立保存自己的配置 |

---

## 功能特性

| 功能 | 说明 |
|------|------|
| ⏱️ **自动刷新** | 间隔从 5 秒到数小时可调 |
| 🎲 **随机范围** | 设置最小/最大范围，每轮随机间隔 |
| 🧹 **强制刷新** | 绕过缓存（Ctrl+Shift+R 风格） |
| 🔔 **关键词监控** | 页面文本出现或消失时提醒 |
| ⚠️ **验证码停止** | 检测常见验证码模式，自动停止 |
| 🖼️ **悬浮倒计时** | 页面上的迷你倒计时器 |
| ⌨️ **输入自动暂停** | 在输入框中输入时暂停 |
| 💾 **域名记忆** | 每个站点自动保存设置 |

## 安装

1. 克隆或下载本仓库
2. 打开 `chrome://extensions/`（或 `edge://extensions/`）
3. 开启**开发者模式**
4. 点击**加载已解压的扩展程序** → 选择 `RefreshMate` 文件夹
5. 点击工具栏中的 🔄 RefreshMate 图标开始使用

### 构建

```bash
npm install
npm run build
```

## 隐私

- **activeTab** — 交互时访问当前标签页
- **tabs** — 按域名查找要刷新的标签页
- **storage** — 本地保存设置
- **alarms** — 定时刷新调度
- **notifications** — 关键词提醒的浏览器通知
- **许可证校验** — 匿名设备指纹 + 许可证密钥每 24 小时发送至 `api.annmax1983.com`，不传输浏览数据
