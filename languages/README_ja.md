# RefreshMate
[English](../README.md) | [中文](README_zh.md) | 日本語 | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

ページをカスタム間隔で自動更新し、キーワードの変化を通知する軽量ブラウザ拡張機能。

> Chromium ベース · Manifest V3 · 最小権限 · ローカル処理のみ

---

## RefreshMate を選ぶ理由

ページの変化を監視したいですか？ RefreshMate は設定した間隔でページを自動更新し、キーワードが出現・消滅したときに通知します。株価監視やチケット販売など、時間に敏感なページに最適です。

| 利点 | 詳細 |
|------|------|
| ⏱️ **カスタム間隔** | クイックプリセット（5秒/30秒/1分/5分）+ カスタム入力 |
| 🎲 **ランダム間隔** | 検出を避けるランダム範囲でサイトブロックを防止 |
| 🔔 **キーワード通知** | キーワード出現・消滅時にブラウザ通知 |
| 🔒 **CAPTCHA検出** | CAPTCHA検出時に自動停止 |
| 💾 **サイト別設定** | ドメインごとに設定を独立保存 |

---

## 機能

| 機能 | 説明 |
|------|------|
| ⏱️ **自動更新** | 5秒から数時間まで間隔を設定可能 |
| 🎲 **ランダム範囲** | 最小/最大範囲を設定し、毎回ランダムな間隔 |
| 🧹 **強制更新** | キャッシュをバイパス（Ctrl+Shift+R 相当） |
| 🔔 **キーワード監視** | テキストの出現・消滅を通知 |
| ⚠️ **CAPTCHA停止** | 一般的なCAPTCHAパターンを検出して自動停止 |
| 🖼️ **フローティングオーバーレイ** | ページ上のミニカウントダウンタイマー |
| ⌨️ **入力中自動一時停止** | 入力欄に入力中は一時停止 |
| 💾 **ドメイン記憶** | サイトごとの設定を自動保存 |

## 無料版 vs Pro版

| 機能 | 無料版 | Pro版（ライセンス） |
|------|--------|---------------------|
| 🗂️ **同時に更新するタブ** | **同時に1タブのみ** | ✅ 無制限 |
| 🎲 **ランダム間隔範囲** | — | ✅ |
| 🔔 **キーワード/正規表現アラート** | — | ✅ |
| 🔄 **任意のページ変化検出** | — | ✅ |
| 🆘 **優先サポート** | — | ✅ |

無料版はブラウザ全体で**同時に1つのタブのみ**自動更新できます。Pro版にアップグレードすると複数タブを同時に更新できます。

## インストール

1. このリポジトリをクローンまたはダウンロード
2. `chrome://extensions/`（または `edge://extensions/`）を開く
3. **デベロッパーモード**を有効にする
4. **パッケージ化されていない拡張機能を読み込む** → `RefreshMate` フォルダを選択
5. ツールバーの 🔄 RefreshMate アイコンをクリックして開始

### ビルド

```bash
npm install
npm run build
```

## プライバシー

- **activeTab** — 操作時に現在のタブへアクセス
- **tabs** — 更新するタブをドメインで検索
- **storage** — 設定をローカルに保存
- **alarms** — 更新タイマーのスケジュール
- **notifications** — キーワード通知用のブラウザ通知
- **ライセンス検証** — 匿名デバイスフィンガープリント + ライセンスキーを24時間ごとに `api.annmax1983.com` へ送信。閲覧データは送信されません
