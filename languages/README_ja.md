# RefreshMate

[English](../README.md) | [中文](README_zh.md) | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

ランダム間隔とキーワード変化アラートによるカスタマイズ可能な自動ページリフレッシュができる軽量ブラウザ拡張機能です。

> Chromium系ブラウザ対応 · Manifest V3 · 最小限の権限 · ローカル処理のみ

---

## RefreshMateの特長

ページの変更を監視したいことがありますか？RefreshMateはスケジュールに従ってページを自動リフレッシュし、キーワードが出現または消滅した際にアラートを通知します。株価監視、チケット販売、タイムセンシティブなページに最適です。

| 特長 | 詳細 |
|-----------|--------|
| ⏱️ **カスタム間隔** | クイックプリセット（5秒/30秒/1分/5分）＋カスタム入力 |
| 🎲 **ランダム間隔** | サイトブロックを回避するためのランダム範囲設定 |
| 🔔 **キーワードアラート** | キーワードの出現・消滅時にブラウザ通知 |
| 🔒 **CAPTCHA検出** | CAPTCHA検出時に自動的にリフレッシュを停止 |
| 💾 **サイト別設定** | 各ドメインごとに設定を個別保存 |

## 機能一覧

| 機能 | 説明 |
|---------|-------------|
| ⏱️ **自動リフレッシュ** | 5秒から数時間までの間隔を設定 |
| 🎲 **ランダム範囲** | 最小/最大範囲を設定し、各サイクルで間隔をランダム化 |
| 🧹 **ハードリフレッシュ** | Ctrl+Shift+Rスタイルのリロードでキャッシュをバイパス |
| 🔔 **キーワード監視** | ページ上のテキスト出現・消滅時にアラート |
| ⚠️ **CAPTCHAストップ** | 一般的なCAPTCHAパターンを検出し、自動停止 |
| 🖼️ **フローティングオーバーレイ** | ページ上のミニカウントダウンタイマー |
| ⌨️ **自動一時停止** | 入力フィールドでのタイピング中に一時停止 |
| 💾 **ドメイン記憶** | サイト別設定を自動保存 |

## 無料版 vs Pro

| 機能 | 無料版 | Pro（ライセンス） |
|------------|------|----------------|
| 🗂️ **同時タブ数** | **1タブ**まで | ✅ 無制限 |
| 🎲 **ランダム間隔範囲** | — | ✅ |
| 🔔 **キーワード／正規表現アラート** | — | ✅ |
| 🔄 **ページ変化検出** | — | ✅ |
| 🆘 **優先サポート** | — | ✅ |

無料版はブラウザ全体で**1タブずつ**しかリフレッシュできません。Proにアップグレードすると、複数タブを同時にリフレッシュできます。

## インストール

1. このリポジトリをクローンまたはダウンロードします
2. `chrome://extensions/`（または`edge://extensions/`）を開きます
3. **デベロッパーモード**を有効にします
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、`RefreshMate`フォルダを選択します
5. 🔄 RefreshMateアイコンをクリックして開始します

### ビルド

```bash
npm install
npm run build
```

## プライバシー

- **activeTab** — 拡張機能との操作時に現在のタブにアクセス
- **tabs** — ドメインでリフレッシュ対象のタブを検索
- **storage** — 設定をローカルに保存
- **alarms** — リフレッシュタイマーをスケジュール
- **notifications** — キーワードアラート用のブラウザ通知
- **ライセンス検証** — 匿名デバイスフィンガープリント＋ライセンスキーが24時間に1回`api.annmax1983.com`に送信されます。閲覧データは送信されません。
